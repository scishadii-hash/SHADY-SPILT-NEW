# SHADY SPILT

Progressive Web App. Open the deployed site in a browser and choose Install app / Add to Home Screen.

## بوت السعرات (مساعد التغذية)

المحرك كله في `bot/` (من غير أي مفاتيح أو سيرفر):

| ملف | وظيفته |
|---|---|
| `bot/foods-eg.js` | قاعدة ~100 صنف (مصري + عام) لكل 100 جم، أوزان الوحدات (رغيف، طبق، معلقة...)، ونسخ الطهي |
| `bot/engine.js` | تطبيع العربي، الأرقام (عربية/إنجليزية/كلمات/كسور)، الوحدات، المحلل |
| `bot/bot.js` | حساب الأصناف والإجماليات، الطهي، البحث الأونلاين الصارم (Open Food Facts) |
| `bot/brain.js` | فهم النية: حساب/زيادة/شيل/تصحيح/سؤال/تسجيل/اليوم/المتبقي + أسئلة التوضيح |
| `tests/bot.test.js` | 64 اختبار: `node tests/bot.test.js` |

التسجيل بيتم عبر نفس نظام الأكل في `index.html` (`S.food[date]`)، والبوت مش بيحتفظ بأي نظام تسجيل منفصل.
